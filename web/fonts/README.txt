Why it is here: the server sends `Content-Security-Policy: default-src 'self'`, so a web font has
to be served from this origin; linking one from a font CDN would be blocked and would also tell
the CDN which visitors loaded the page. One variable file carries every weight and the condensed
width used for the receipt text, so the page needs no second font.
