# BUG-001 · The "1.65 points of leakage" figure does not reproduce

> Field Guide habit #5 — one file, start to finish.

**Status:** fixed in the documents; **cause of the original figure UNKNOWN** (reproduce-first)
**Found:** 2026-09-29 by Claude Sonnet 5.5, while re-measuring inherited numbers for Phase A · **Severity:** P1

---

## Symptom

`AUDIT-2026-08-26.md` C-1, `FLOW.md` F-1 and `HANDOVER.md` all stated that fitting the vectorizer
before the split cost 1.65 accuracy points (BernoulliNB 0.8350 as written, 0.8185 leak-free). Nine
documents and a test comment repeated it. Re-running the same comparison gave no such gap.

## Reproduce

The two measurement scripts lived in the session scratchpad and are not in the repository. Their
logic is fully described in `DECISIONS.md` D-009: sample 10,000 rows at seed 42, clean exactly as
the notebook does, split 80/20 at seed 42, and compare a vectorizer fit on all rows against one
fit on the training rows only.

**Expected (per the audit):** leak-free BernoulliNB about 0.8185.
**Actual:** 0.8355. Other models moved by −0.0020 to +0.0010.

## Hypotheses falsified

| # | Hypothesis | Evidence that killed it |
|---|---|---|
| 1 | My pipeline differs from the notebook's | The as-written column reproduced the notebook's committed outputs exactly: 0.7820 / 0.8255 / 0.8350 / 0.8330 |
| 2 | An index split differs from an array split | `train_test_split` on indices and on the cleaned texts, same seed, produced identical partitions (`True`) |
| 3 | One lucky split seed | Ten split seeds: as-written minus leak-free between −0.0050 and +0.0055, mean −0.0010 to +0.0000, std 0.0013 to 0.0031 |

## Root cause

**UNKNOWN.** The script that produced the 2026-08-26 figures was never committed, so the
discrepancy cannot be traced. Not tested: a different scikit-learn or numpy version on that day
(`requirements.txt` was unpinned, so the versions are unrecorded). No cause is claimed.

## Fix

Documentation only. `DECISIONS.md` D-009 records the re-measurement and supersedes the old
figures; README, CONSTRAINTS, AGENTS, CONTRIBUTING, FLOW, HANDOVER and a test comment were
corrected; the audit carries a dated erratum. The rule (fit on train only) is unchanged.

## Verification

After the corrections the suite was still green (`31 passed, 19 xfailed`), and the old figures
appear only in D-009 and the audit erratum, which quote them in order to retire them.

## Follow-ups

Any future comparison of this kind must commit its measurement script, or its numbers stay
testimony. If the 2026-08-26 figure ever needs explaining, start by pinning old package versions.
